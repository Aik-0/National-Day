Python Code

Uses OpenCV to draw an image, display Arabic lyrics, animate the Saudi flag, and send signals to Arduino.

Arduino Code

Controls five LEDs and a buzzer to play musical notes and create a light show for 48 seconds.

## Arduino Prototype

This project includes an Arduino prototype for the Saudi National Day show.

- **Platform:** Wokwi
- **Components:** Arduino, 5 LEDs, and a buzzer
- **Features:** Sequential LED lighting, musical tones, and a final flashing effect.
- **Duration:** 48 seconds
